# LEPÍ Android — версия 1.0.0

Нативное Android-приложение LEPÍ на Kotlin и Jetpack Compose.

## Открытие проекта
1. Откройте папку `android-app` в Android Studio.
2. Используйте JDK 17 и дождитесь Gradle Sync.
3. Запустите конфигурацию `app` на устройстве или эмуляторе с Android 7.0+.

## Возможности
- Адаптивный интерфейс для телефонов и планшетов.
- Каталог из 12 товаров с фотографиями исходного сайта LEPÍ.
- Поиск, фильтрация по категориям и карточки с составом.
- Корзина с сохранением на устройстве.
- Актуальные статусы наличия из действующего API.
- Отзывы с фотографиями.
- Оформление заказа через действующий сервер LEPÍ.
- Фирменная палитра, типографика и оформление LEPÍ.

## Интеграция
- API: `https://lepi-orders.onrender.com`
- Сайт: `https://lepikatalog.onrender.com`
- Фотографии: папка `images/` основного репозитория.

Секретные ключи Supabase и Telegram не включаются в Android-приложение. Заказы проходят через сервер LEPÍ.
